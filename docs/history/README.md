# 历史工作记录

本目录保存阶段性工作记录、历史施工单、执行结果、专项审计和过往方案。

**归档只表示该文档不再是仓库根目录的当前工作入口，不代表其中每一项工作都已成功完成，也不代表所有遗留事项都不再需要关注。** 执行前应核对当前代码、部署状态和最新验收证据。

- 当前产品方向、能力范围与实施顺序以仓库根目录 `README.md` 和 `docs/v2/` 为准。
- 本目录文档用于追溯决策背景、实施过程、未完成事项和验收证据，不自动构成当前产品需求。
- 文档中的历史路径、版本号、测试数量和环境信息只代表记录时点；执行前必须重新核实。
- 若历史记录与当前代码或 v2 架构冲突，以当前代码、当前测试和已接受的 v2 决策为准。

历史记录尽量保留原始内容；仅在归档迁移导致链接失效时修正路径。
