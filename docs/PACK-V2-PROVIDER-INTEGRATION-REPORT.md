The Mac account card now distinguishes configured capabilities, implemented
modern connector stage and verified capabilities. Swift and Node inventory
reports share stage names and fixture rows. The existing profile IDs are
not renamed: chatgpt/openai and gemini/gemini-api remain distinct local
modes. Muse compatibility is not the modern native execution path.

OpenAI, Gemini API and Ark have manually authorized text adapters, not
verified real-account execution; ChatGPT has a candidate fixture-tested
DOM driver without a verified live selector or identity observer;
Gemini and Doubao native have isolated login development entrypoints
only. Muse retains both legacy routes. No tools, memory, multimodal or
streaming capability is inferred. The report always says identity and
execution unverified and automatic execution disabled because it has
only local inventory evidence. This does not disable existing manual
execution, change permissions or replace Hub enrollment. UI separately
directs users to the existing dedicated Hub binding page. A configured
tool capability is not an implemented tool.

No stored profile schema changes, migration, credential reads beyond
existing inventory, external requests, new dependencies or startup work.
Future live observations must be scoped, fresh, account-bound and explicitly
authorized before they can change execution claims. The shared fixture
checks stage parity in CI; it does not prove live Provider capabilities.
